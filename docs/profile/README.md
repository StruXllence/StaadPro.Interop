# StruXllence

Created and maintained by **Srinivasa Rao Masanam**.

StruXllence builds open-source tools for structural engineering, with a focus on C#/.NET and STAAD.Pro automation.

## Featured project

### [StaadPro.Interop](https://github.com/StruXllence/StaadPro.Interop)

A strongly typed .NET Framework wrapper for Bentley STAAD.Pro's OpenSTAAD COM API. The library provides managed interfaces for geometry, loads, properties, supports, commands, design queries, and analysis results.

- [Get started](https://github.com/StruXllence/StaadPro.Interop#installation)
- [Explore the API guides](https://github.com/StruXllence/StaadPro.Interop/tree/main/docs)
- [Run a read-only example](https://github.com/StruXllence/StaadPro.Interop/tree/main/examples/ReadModel)
- [See the roadmap](https://github.com/StruXllence/StaadPro.Interop/blob/main/ROADMAP.md)

## Collaborate

I welcome documentation improvements, offline regression tests, practical automation examples, and reproducible bug reports. You can contribute to the managed code and offline tests without installing STAAD.Pro.

Read the [contribution guide](https://github.com/StruXllence/StaadPro.Interop/blob/main/CONTRIBUTING.md), browse [beginner issues](https://github.com/StruXllence/StaadPro.Interop/labels/good%20first%20issue), or [propose a focused improvement](https://github.com/StruXllence/StaadPro.Interop/issues/new/choose).

Have a structural automation use case? Open an issue in the relevant project with a small example and the workflow you would like to improve.
